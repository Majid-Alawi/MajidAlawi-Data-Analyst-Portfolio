## Repository Navigation & Structure

To deep-dive into the architectural lineage, production code scripts, or dashboard snapshots of a specific project framework, simply click into its respective folder directory above. 

Each directory is arranged using standard enterprise repository parameters:
*   `/Data` — Houses local source file templates and pristine exported matrices.
*   `/SQL` or `/Scripts` — Contains master `.sql` query files.
*   `.ipynb` — Advanced Python Jupyter Notebook cleaning files.
*   `README.md` — Complete, human-written technical case-study documentation.
